Map Representation: Graph G(V, E)

Theoretical Model

The city road grid is represented as a high-density Directed Weighted Graph:

  • Vertices (V): 15+ District nodes (Maadi, Nasr City, Downtown).
  • Edges (E): Directed road segments with dynamic weights.
  • Weights (W): Dynamic cost = Distance × (1 + Congestion).

Algorithm 2: Fleet Resource Allocation

The Car Calling Problem

Matching passengers to limited vehicles is a Combinatorial Optimization problem. We map this to the 0/1 Knapsack Problem.

This ensures we maximize the "Value" (passenger coverage) without exceeding "Capacity" (available fleet).

Alamein International University | AI Track

Dynamic Programming (DP) Logic

DP[i, w] = max(DP[i-1, w], Vᵢ + DP[i-1, w-wᵢ])

Optimal Substructure

Implemented in Python using a bottom-up DP table. The system calculates the maximum passenger utility by considering each route-car combination iteratively.

Complexity: O(N × W) where N is routes and W is total car capacity.

Alamein International University | AI Track

Greedy vs. DP Allocation

Greedy Approach

Fast (O(n log n)) but prone to "local optima". It often misses the most efficient global fleet distribution.

Dynamic Programming

Guarantees global optimality. Our simulation shows a **significant increase** in total passenger coverage compared to greedy matching.
